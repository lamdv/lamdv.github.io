GreenCSR (Viettel) — the bet: agentic SDLC as an operating model

The vision. A corporate social responsibility (CSR) platform for Viettel, a large Vietnamese payment provider — approached as a test of a thesis: that developers and agents working as Human-Agent Teams (Cross-HAT) can ship enterprise software at an order of magnitude lower cost without adopting one heavyweight framework. Delivered in 3 months against an original 300 man-month / 9-month estimate, at 36 man-months and $3,000 in token cost. Led 9 engineers.

Setting the direction. Rather than enforce tooling, I defined the invariants the team must share — architecture, work division, API contracts — and left each developer's agent workflow free. Before: "vibe requirements, vibe architecture," scattered documentation, each developer working sporadically with fragmented tooling (BMAD, Superpower, …).

  • Held the thesis under pressure from above to wrap the method in a heavyweight tool; the core insight is human judgment + a git-native context, not software-enforced workflow.
  • Git-native — introduced no new tool. A versioned .wiki/ carries shared context across four authority layers (L0 canon / L1 forum / L2 godview / L3 private workbench); facts climb only by explicit promotion.
  • Each developer owns their own agents — a HAT = one developer + their agents — with only quality and integration quality gated centrally.
  • New developers contribute on day 1; 3 developers worked the same project with no friction.
  • Transferred to 3–4 additional teams, turning a project tactic into org capability — then taught it forward via a 2-week Agentic SDLC course for SBI-FPT and ongoing coaching of 4–5 engineers.
