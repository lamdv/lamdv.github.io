GreenCSR (Viettel)

The product. A corporate social responsibility (CSR) platform for Viettel, a large Vietnamese payment provider. Delivered in 3 months against an original estimate of 300 man-months over 9 months, at 36 man-months delivered and $3,000 in token cost. Led 9 engineers.

The methodology — Agentic SDLC. The velocity came from a Cross-HAT (Human-Agent Team) collaboration scheme I designed and led, later distilled into a full platform blueprint. Before: "vibe requirements, vibe architecture," scattered documentation, each developer working sporadically with fragmented tooling (BMAD, Superpower, …). The scheme standardises the invariants (architecture, work division, API contracts) while leaving each developer's agent workflow free.

  • Git-native — introduced no new tool. A versioned .wiki/ carries shared context across four authority layers (L0 canon / L1 forum / L2 godview / L3 private workbench); facts climb only by explicit promotion.
  • Each developer owns their own agents — a HAT = one developer + their agents — with only quality and integration quality gated centrally.
  • New developers contribute on day 1 with agents assisting comprehension; 3 developers worked the same project with no friction.
  • Held the thesis against pressure from above to wrap it in a heavyweight tool; transferred to 3–4 additional teams with good results.
  • Delivered a 2-week Agentic SDLC course for SBI-FPT and coach 4–5 engineers informally on an ongoing basis through the method.
